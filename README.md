# Studio Evolution Tech — Formulário

## Vamos criar seu projeto?

Formulário independente com as 27 perguntas originalmente desenvolvidas em `studio-evolution-tech/projeto/index.html`, preservando a identidade escura, ciano e roxo do Studio.

- Seis etapas de perguntas e uma etapa de revisão.
- Layout responsivo com campos de 16 px e botões que se reorganizam no celular.
- Nome obrigatório; demais respostas opcionais.
- Resumo completo para revisão e opção de copiar as respostas.
- Envio para o WhatsApp **+55 (27) 99999-8911**. O cliente confirma o envio no aplicativo.
- Sem banco de dados, rastreamento ou armazenamento de respostas no site.

## Publicação

GitHub Pages, branch `main`, pasta `/ (root)`.

Endereço: https://arnoldsuheth.github.io/studio-evolution-formulario/

## Manutenção

O site é estático e autocontido em `index.html`. Edite a constante `phone` para mudar o destino do WhatsApp. As fontes externas têm alternativa local sans-serif.

O repositório principal `studio-evolution-tech` não é modificado por este projeto.
